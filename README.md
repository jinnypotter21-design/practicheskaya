# Task Manager

## О проекте

**Task Manager** — небольшое веб-приложение для управления личными задачами.

Приложение позволяет пользователю создавать и просматривать задачи, отмечать их как выполненные и удалять завершённые задачи.

Проект разработан с использованием стандартных веб-технологий и не требует установки дополнительных зависимостей.

## Возможности

С помощью приложения пользователь может:

* создавать новые задачи;
* просматривать список задач;
* отмечать задачи как выполненные;
* удалять выполненные задачи.

## Используемые технологии

В проекте используются следующие технологии:

| Технология | Назначение                         |
| ---------- | ---------------------------------- |
| HTML       | Создание структуры веб-страницы    |
| CSS        | Оформление и стилизация интерфейса |
| JavaScript | Реализация логики приложения       |
| JSON       | Хранение данных о задачах          |

## Требования

Для работы с проектом необходимо:

* современный веб-браузер;
* локальная копия проекта.

**Дополнительная установка зависимостей не требуется.**

## Запуск проекта

### Вариант 1. Открытие HTML-файла

Основную страницу приложения можно открыть непосредственно в браузере:

```text
src/index.html
```

После открытия файла пользователь сможет работать с интерфейсом приложения.

### Вариант 2. Запуск через локальный HTTP-сервер

Для запуска через локальный сервер выполните следующие действия:

1. Откройте терминал в корневой папке проекта `task-manager`.
2. Запустите локальный HTTP-сервер командой:

```bash
python -m http.server 8000
```

3. Откройте в браузере следующий адрес:

```text
http://localhost:8000
```

После этого откроется проект, доступный через локальный HTTP-сервер.

> **Примечание:** для выполнения команды требуется установленный Python.

## Данные приложения

Данные о задачах хранятся в файле:

`data/tasks.json`

Каждая задача содержит идентификатор, название и информацию о том, выполнена ли она.

Пример содержимого файла:

```json
[
  {
    "id": 1,
    "title": "Подготовить документацию",
    "completed": false
  }
]
```

### Поля задачи

* `id` — уникальный идентификатор задачи;
* `title` — название задачи;
* `completed` — статус выполнения задачи:

  * `false` — задача не выполнена;
  * `true` — задача выполнена.
